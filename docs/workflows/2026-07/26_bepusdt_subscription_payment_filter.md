# BEPUSDT 订阅支付方式筛选修复

## 问题

Default 与 Classic 的订阅购买入口会把类型为 `bepusdt` 的支付方式
无条件排除出易支付列表。管理员未启用原生 BEPUSDT 网关、但在易支付中
配置了同名支付类型时，该支付方式因此无法显示。

## 修改范围

- 原生 BEPUSDT 已启用且存在可用链时，继续过滤 `bepusdt` 与 `usdt`
  类型，避免原生入口和易支付入口重复显示。
- 原生 BEPUSDT 未启用时，不再过滤这两个类型，保留管理员配置的易支付
  方式。
- Default 与 Classic 使用一致的筛选规则。

本次修改只影响订阅购买界面的支付方式展示，不改变充值接口、支付回调、
订单状态或签名验证。

## 兼容性与安全边界

- 不新增接口、配置或数据迁移。
- 是否使用原生 BEPUSDT 仍由后端返回的启用状态和链列表共同决定。
- 支付请求仍由现有后端接口校验，前端展示规则不作为安全边界。

## 验证计划

1. 原生 BEPUSDT 关闭时，确认类型为 `bepusdt` 或 `usdt` 的易支付方式
   可出现在订阅购买界面。
2. 原生 BEPUSDT 开启且存在链配置时，确认只显示一个原生 USDT 入口。
3. 分别执行 Default 类型检查和 Classic 格式检查。
4. 执行 `git diff --check`。
