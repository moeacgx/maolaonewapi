# 充值用途提示跟随余额购买订阅开关

## 问题

充值页面固定展示“充值余额不可用于购买订阅套餐”，但系统允许管理员开启余额购买订阅。开关开启时，提示与实际能力冲突。

## 修复

- Classic 和 Default 充值页面统一读取 `/api/user/topup/info` 的 `enable_balance_subscription`。
- 仅当该字段明确为 `false` 时展示两行充值用途提示。
- 字段为 `true` 时隐藏提示；加载期间或旧后端未返回该字段时也隐藏，避免错误提示闪烁，并保持旧版本兼容行为。
- 不修改余额购买、支付合规、订阅结算及权限逻辑。

## 验证

1. 运行两套前端的开关联动源码测试。
2. 执行 Default 类型检查及两套前端生产构建。
3. 对本次修改文件执行 Prettier 检查。
4. 执行 `git diff --check`。
