# 充值余额与订阅套餐用途提示

## 变更目标

在余额购买订阅关闭时，于充值操作区明确区分充值余额与订阅套餐，避免用户误以为充值后的余额可用于购买订阅套餐；开启余额购买订阅后不展示与实际能力冲突的提示。

## 变更范围

- Classic 充值页在 `enable_balance_subscription` 明确为 `false` 时，于额度充值内容顶部展示用途提示。
- Default 钱包页在 `enable_balance_subscription` 明确为 `false` 时，于充值卡片顶部展示同等提示。
- 提示文案支持两套前端现有的全部界面语言。

## 页面文案

- 充值余额仅用于 API 调用消耗，不可用于购买订阅套餐。
- 订阅套餐请在「订阅套餐」页面单独购买。

余额购买订阅开启时隐藏上述两行提示。接口尚未返回配置或旧后端缺少该字段时也不提前显示，避免加载期间闪烁错误文案。本次仅完善充值页展示逻辑，不修改充值、订阅购买、支付、结算或权限逻辑。

## 安全与兼容性

- 不展示账户、订单或支付敏感信息。
- 不新增接口、配置、数据结构或数据库迁移。
- 保持现有充值与订阅功能行为不变。

## 已知限制

- 提示依赖 `/api/user/topup/info` 返回的 `enable_balance_subscription` 有效状态；该状态同时受支付合规确认约束。
- 当前普通用户套餐购买组件仍嵌在充值页，独立的 `/subscriptions` 路由是管理员套餐管理页。本次文案调整不负责拆分普通用户购买页面。

## 验证计划

1. 关闭余额购买订阅，检查 Classic 与 Default 充值区域均展示两行提示。
2. 开启余额购买订阅，检查两套前端均隐藏提示。
3. 检查各语言翻译键完整且 JSON 格式有效。
4. 执行 Default 前端类型检查与相关代码格式检查。
5. 执行 `git diff --check`，确认没有空白符错误。
