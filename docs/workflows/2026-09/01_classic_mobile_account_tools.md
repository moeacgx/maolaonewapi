# Classic 手机端右侧菜单账号工具

## 目标

Classic 手机端使用右侧菜单承载导航。移动端菜单需要提供与桌面端一致的
个人中心、通知、语言和主题切换入口，顶部栏只保留菜单按钮，避免操作入口重复。

## 修改范围

- `PricingTemplateHeader` 的移动菜单复用现有 `UserArea`、`NotificationButton`、
  `LanguageSelector` 和 `ThemeToggle`。
- 将主题切换从手机顶栏移入右侧菜单，与通知和语言按钮放在同一组工具中。
- 账号区域继续使用桌面端的个人设置、令牌、钱包和退出登录菜单；通知继续打开
  既有公告弹窗；语言切换继续调用现有语言偏好保存逻辑。
- 仅覆盖 Classic 模板，Default 模板不受影响。

## 移动端布局与可访问性

右侧菜单主体可独立纵向滚动，账号工具区域和底部控制台/登录入口保持可达。
菜单按钮继续通过 `aria-expanded` 和 `aria-controls` 表达展开状态；工具按钮沿用
各自组件的可访问名称和图标。

## 兼容性与边界

后端 API、权限判断、通知已读状态和语言存储契约均不变。桌面端控件位置和行为不变。
移动端菜单打开时继续锁定页面滚动，并在切换到桌面宽度时自动关闭。

## 验证

- 使用 Classic Node 原生契约测试确认移动菜单包含账号、通知、语言和主题工具。
- 确认手机顶栏不再渲染这些重复工具。
- 执行 Classic 受影响文件的 Prettier 检查和 `git diff --check`。
