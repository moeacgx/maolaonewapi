# 福利券页面移除流水入口与表格右侧操作列修复

## 问题

福利券用户卡片和管理员券列表仍显示“查看流水”，与当前页面的简化操作范围不符。
Classic `/console/redemption` 的福利活动表使用固定 `scroll.x`，操作列没有贴到业务面板右侧。

## 变更范围

- Default 用户福利页：移除用户券卡片的查看流水按钮和页面级流水抽屉挂载。
- Default 管理员福利券列表：移除券表的查看流水按钮和管理员流水抽屉挂载；保留批量作废。
- Classic 用户福利页：移除用户券卡片、页面和福利数据 hook 的流水入口及状态。
- Classic `/console/redemption` 福利活动券列表：移除单券流水菜单项和流水抽屉；保留单券/批量作废。
- Classic 活动表和券表：操作列增加 `fixed: 'right'`，表格滚动宽度改为 `100%`，使操作列随容器贴右。

流水数据表、用户/管理员流水 API 和独立流水组件未删除，继续作为审计与对账能力保留；本次仅
收紧页面入口，不改变权限、账务或历史数据生命周期。

## 验证

- Classic 福利、活动管理和 hook 契约测试：47/47 通过。
- Classic 受影响文件 ESLint：通过。
- Classic 受影响文件 Prettier：通过。
- `git diff --check`：通过。
- Default Vitest/类型检查暂无法在当前工作树执行，因为该工作树没有 `web/node_modules`；已通过
  代码检查确认 Default 页面不再引用流水组件或入口，需在有依赖的环境补跑 Default 受影响测试。
