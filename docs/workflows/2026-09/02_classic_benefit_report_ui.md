# Classic 福利活动报表可读化

## 目标

将管理端福利活动报表从原始 quota 字段列表改为面向运营人员的金额和发放状态概览，
并把活动行内操作收敛为单一操作菜单，减少表格换行和视觉噪声。

## 变更范围

- 仅修改 Classic 模板 `web/classic/src/components/table/benefits/BenefitActivitiesPanel.jsx`；
  Default 模板和后端 API 不变。
- 报表展示总预算、已发放、已使用、剩余可用、资金使用进度、金额去向、发放状态和活动设置。
- 报表金额按活动响应中的人民币总金额与总 quota 比例换算，不直接显示 `total_quota` 等内部字段。
- 报表读取现有券列表接口补充已发放数量、领取用户去重、已使用和过期券统计。
- 活动表格的发布/暂停/恢复/提前结束/编辑/终止/报表/券列表聚合到“操作”下拉菜单，
  菜单分为活动管理和数据查看两组。

## 兼容性与边界

- API 路径、请求参数、数据库字段和状态机不变。
- 报表加载会额外读取当前活动的券列表，用于数量和状态统计；接口失败时沿用统一操作失败提示。
- `expired_unused_quota` 仍按后端定义展示为过期未使用金额，过期券数量来自券列表状态统计。

## 验证

- Classic 契约测试覆盖报表结构和单一操作菜单入口。
- Classic 受影响文件通过 ESLint、Prettier 和 Vite 生产构建。
- `git diff --check` 通过。
