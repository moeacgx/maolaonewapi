# Classic 模型广场与控制台回归修复

日期：2026-08-28

## 背景

本次修复先对照历史提交 `943f29ef2`、`3012b957a`、`df09928a7`、
`f57d2890d` 和 `daed310c1`，并核对对应工作流文档。历史记录表明：

- `943f29ef2` 已移除模型卡片标题旁的价格调整标签，以及端点、能力、
  `+N` 和计费单位等易变元数据；本次不恢复这些内容。
- `3012b957a` 将分组价格行的 variant rules 噪声移出详情展示；本次只
  保留需要的规格价格，不在详情表格重复渲染规则。
- `df09928a7` 建立了模型分组的稳定语义颜色；本次继续使用该颜色契约。
- `f57d2890d` 曾恢复首页性能概览，`daed310c1` 随后明确回滚了该面板；
  当前 HEAD 确认缺少 `PerformanceOverviewPanel`，因此按历史实现恢复。

## 可见契约

- 模型卡片底部的计费摘要与延迟、吞吐、状态摘要在同一底边对齐，卡片
  内容不因模型能力数量变化而跳动。
- 模型详情的价格调整继续以倍率语义显示：小于 1 为“折”，大于 1
  为“倍”；详情表格不显示 variant rules 噪声，供应商和分组保留既有
  语义分组颜色。
- 管理员 Classic 控制台首页按 `StatsCards -> PerformanceOverviewPanel
  -> RevenuePanel` 顺序显示性能平铺面板。面板展示成功率、平均延迟、
  首 Token 延迟、吞吐量和模型明细，并分别处理加载、空数据及 API 错误，
  不创建测试数据。
- Classic 移动端模板顶栏复用既有 `NotificationButton` 和 `UserArea`，
  保留未读徽标、通知打开动作和用户下拉菜单；入口具有可访问的
  `aria-label`/`title`。移动模板菜单状态与控制台侧栏抽屉状态保持独立，
  桌面布局不变。

## 修改范围

仅修改 `web/classic`、本目录工作流文档和开发文档索引。未修改后端、
数据库、部署配置或远程资源，也未恢复历史上已删除的卡片元数据。

性能面板调用现有 `GET /api/perf-metrics/summary` 接口，使用可取消请求，
在组件卸载后不更新状态；接口无模型时显示空状态，请求失败时显示错误状态。
