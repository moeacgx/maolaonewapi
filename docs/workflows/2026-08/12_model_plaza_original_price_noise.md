# 模型广场原价噪音收敛

## 问题

模型广场卡片、表格和详情分组价格表在已经显示折后价与折扣标签的同时，额外逐行展示“原价”。对规格价格较多的图片模型，这会把价格摘要拉得很长，核心价格信息被噪音淹没。

## 根因

Classic 模型广场的卡片、表格和详情表都从 `getModelPriceItems` 取得 `originalValue` 并无条件渲染原价；折扣标签也会在综合折扣为 1 时显示“原价”。Default 当前模型广场没有逐行原价展示，本次不改其数据和价格计算。

## 修改范围

- Classic 卡片视图：只在综合折扣小于 1 时显示折扣标签，不再显示“原价”标签。
- Classic 表格视图：移除价格项下方的逐行原价。
- Classic 详情分组价格表：移除规格价格项下方的逐行原价；仅当至少一个分组存在折扣时显示“综合折扣”列。
- 新增 `hasBillingDiscount` 统一复用折扣判断阈值。

## 兼容性

- 不修改计费、倍率、分组、接口或模型价格计算。
- 折扣价、规格价格、计费单位和倍率显示保持不变。
- 大于 1 的加价倍率不再在模型广场作为“综合折扣”列展示；用户要求只保留有折扣的显示。

## 验证

- `npm run build`（web/classic）
