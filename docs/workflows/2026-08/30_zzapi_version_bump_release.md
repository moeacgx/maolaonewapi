# zzapi 版本号更新与发版

日期：2026-08-30

## 目标

将当前 zzapi 主线版本号提升到下一版，便于后续打 tag、出 release，
并让二进制与前端构建读取到一致的版本标识。

## 修改范围

- 根目录 `VERSION` 从 `v1.0.0-rc.10.1.10.264` 提升到
  `v1.0.0-rc.10.1.10.278`。
- 同步更新开发文档索引，保留可追溯的发版记录。

## 兼容性与边界

- 不改 API、数据库、运行逻辑或部署拓扑。
- 只影响后续构建产物展示的版本号和 release 标识。

## 验证计划

- 检查 `VERSION` 文件是否已更新为目标版本。
- 执行 `git diff --check`。
