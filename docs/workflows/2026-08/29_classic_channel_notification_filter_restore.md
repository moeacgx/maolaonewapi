# Classic 渠道关闭通知筛选恢复

## 问题

通知中心后端已支持 `channel_disabled` 的状态码和多个报错关键词筛选，Default 页面也提供了对应控件；Classic 页面只有任务加载和保存字段，没有编辑控件，因此无法新建或修改关键词白名单通知。

## 修改

- Classic 渠道关闭事件显示状态码筛选输入。
- 使用标签输入支持连续添加多个报错关键词，保存前去空格并按不区分大小写的匹配语义去重，关键词保持后端的 OR 语义。
- 非渠道关闭事件不发送筛选配置，空筛选不写入 JSON。
- 增加筛选归一化 Node 回归测试和中英文界面文案。

## 兼容性与边界

- 后端接口、数据库字段和通知匹配逻辑不变。
- 仅 Classic 管理员通知中心增加编辑能力，已有任务的筛选配置会在打开编辑时回显。
- 状态码格式、关键词数量和长度仍由后端校验。

## 验证

- Classic 筛选归一化 Node 测试通过，覆盖多个关键词去重、大小写重复和空值省略。
- Classic i18next 同步、Prettier、ESLint 和 Vite 生产构建通过。
